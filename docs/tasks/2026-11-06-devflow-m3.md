### 实现中发现并解决的设计问题

- **归档前的链接**：archive 技能要在知识页里链接"归档后的 design.md"，但归档前该文件不存在，lint 报错；而 archive 又要求 lint 无错误，两边卡死。改为：链接指向某个进行中变更归档后的位置、且文件已在变更目录里时，lint 视为有效。
- **构建产物**：`mvn test` 生成 `target/`，若未被 `.gitignore` 忽略，工作树哈希会变，verify 结果永远是 unknown（这是设计上的保护）。演示项目补了 `.gitignore`。
- `archiveTarget` 移到 `core.ts`，避免 wiki 与 archive 循环引用。

### 遗留

- 端到端里"人"的步骤由脚本代办（审查意见是我按 M2 发现的问题写的）。真实使用时还需要人亲自走一遍。
- 两次 Agent 运行各有 1 次权限拒绝（想用 `for … cat` 一次读多个文件），不影响结果；可以考虑在技能里提示用 Read 工具。
- verify 超时固定 30 分钟（`src/exec.ts` 中的 shortcut 注释）。
- 前端没有验证命令：真实项目应在 `project.yaml` 加 `npm run build`。
