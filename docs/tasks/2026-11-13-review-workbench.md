# 审查提效：决策优先的审查页、本地审查台、多仓库哈希

## 目标

- 审查页首屏只放要人拍板的事项和方案要点，细节默认折叠。
- 批准、确认人工证据、归档都能在浏览器里一键完成，不用再去终端逐条敲命令。
- 代码在兄弟仓库时，代码哈希覆盖这些仓库；方案小改后重新批准，不用重录没受影响的证据。

依据：gz-north-second-ring 两个变更的事件日志与会话记录（2026-11-12）。用户选择跳过 devflow 提案，直接改代码。
