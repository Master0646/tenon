# 审查台变更页重排

## 为什么

- 页面很长，没有一直可见的目录，要找某个面板只能来回滚动。
- 操作栏在页面底部，和首屏的待拍板事项离得远，不好找。
- 首屏放了待拍板事项、方案要点和影响范围，却没有直接说明现在到哪一步、要我做什么。
- 批注发出去就看不到了，不知道发过什么、Agent 读了没有。

## 改什么

- 左侧加固定目录，显示面板和面板状态，点击就跳转。
- 操作栏移到顶部并固定。
- 首屏改为：进度条与当前工作节点、要你做什么、待拍板事项。
- 方案要点和影响范围移到首屏下方的独立面板。
- 新增「批注记录」面板。

## 影响

- 审查台的变更页布局全部调整。
- 离线审查页只有首屏内容跟着变，没有目录、顶部操作栏和批注记录。

## 不做什么

- 不改面板内部的内容和顺序（A 提案到 E 被审文件）。
- 批注记录只读：不能在记录里修改或撤回已发送的批注，也不记录 Agent 的回复。
- 不改首页和已归档只读页的布局。
