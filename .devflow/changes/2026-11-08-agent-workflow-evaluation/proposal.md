# 真实 Agent 工作流对照与闭环效果评测

## 为什么
- 从 2026-11-08-evidence-and-improvement-loop 原 T12 承接未执行的真实评测，保留后续验收责任。
- 工程回归通过不能单独证明工具降低了真实开发的漏检、介入次数或耗时。

## 改什么
- 补齐隔离运行器，冻结项目、工具、模型、预算、评分器及逐任务判据。
- 完成一次反馈到候选、提案、修复、固定回归、效果比较与候选结果回填的演示。
- 对错误配置、遗漏权限分支、新会话恢复分别做基线/候选交替实验，每任务每版本至少五次。
- 输出首轮效果报告、失败明细和证据不足项。

## 影响
- 仅涉及评测脚本、评测资产、测试及结果报告，不修改已交付 CLI 行为。
- 本案保持 draft；运行前另需明确模型、账号额度及执行预算，当前不调用模型。

## 不做什么
- 不自动审批生产变更，不因环境限制改低验收标准，不以模拟数据冒充真实实验。
- 不把真实评测暂缓标为完成，也不因工程变更归档而宣称效率提高。
