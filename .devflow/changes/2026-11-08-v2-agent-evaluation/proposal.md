## 为什么
- 首轮 30 次运行未触发 v2 证据流程，且答复写入指令冲突产生 unknown，无法证明新版收益。
## 改什么
- 新建独立协议和运行入口，对照同一 CLI 的 v1 与 v2 工作流，覆盖证据缺失、代码变化后证据过期、人工验收未确认。
- 每类每组 5 次，共 30 次；先完成离线夹具和评分器验证，再执行真实 Agent 并保留原始记录。
- 同时测量漏检、误拦、正确恢复、工具调用和耗时，未知成本保持 unknown。
## 影响
- 消耗真实 Agent 用量；启动前冻结可用模型、执行通道和可强制执行的额度限制。
- 本轮结论限定为证据工作流效果，不推断所有开发任务的总体效率。
## 不做什么
- 不改生产 CLI、不修改首轮协议和结果、不代人批准或确认、不以自动回归冒充真实 Agent。
