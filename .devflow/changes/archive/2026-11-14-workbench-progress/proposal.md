# 审查台显示工作节点与已归档变更，刷新前先提示

## 为什么

- 首页「轮到你」一列在 Agent 工作时只写「Agent 进行中」，看不出它卡在哪一步。
- 归档后变更就从审查台消失了，回头查当时批了什么只能去翻文件。
- 页面每 5 秒整页刷新一次，会丢掉滚动位置、展开的面板和选中的文字，看到一半就被打断。

## 改什么

- 「轮到你」一列改为「工作节点」：写方案中、待你批准、待开工、实现中（任务 x/y）、补证据中、修复中/待重新验证、待你确认 N 条、归档准备中、待你归档。
- 首页加「已归档」列表，每个已归档变更有只读页。
- 自动刷新改为：查到状态变化时显示「有新进展，点此刷新」，由人点了才刷新。
- 刷新后恢复滚动位置和展开的面板。

## 影响

- 只影响审查台（`devflow review`）的页面。
- 离线审查页（`devflow render`）和命令行输出不变。

## 不做什么

- 不改单个变更审查页的布局，这部分在 `2026-11-14-review-layout` 中做。
- 只读页不提供任何操作，也不能写批注。
- 不做页面局部更新：状态变化后仍然整页刷新，只是改成由人点了才刷新。
