# 将 DevFlow 更名为 Tenon

## 为什么

- 采用 Tenon 作为产品名称，使安装、终端和 Agent 里的名称一致。

## 改什么

- 安装包、CLI、帮助、审查界面、文档和生成的技能改用 Tenon。
- 新项目使用 `.tenon/`，现有项目直接沿用原有的 `.devflow/` 数据。
- 验证并提交后推送到现有远程仓库的工作分支。

## 影响

- 用户和自动化需改用 `tenon` 命令和 `tenon-*` 技能。
- 本仓库沿用现有项目数据目录，确保审批记录在改名期间仍可访问。

## 不做什么

- 不改远程仓库地址，不发布 npm 包，不批量改写历史记录。
